# A11Y-002: The whole lookup and save flow works with the keyboard

| Field | Value |
|---|---|
| Requirement | R1 |
| Priority | P2 |
| WCAG criterion | WCAG 2.1.1 Keyboard |
| Suites | regression, uat |
| Status | Automated |

## Preconditions
The customer maintenance screen is reachable at https://anupsahoo.github.io/progress-agent/customer-maint.

## Steps
1. Use only Tab, Shift+Tab and Enter
2. Look up, edit and save a customer

## Expected result
Every action is reachable and focus is always visible.

## Automated check
```ts
test('keyboard only', async ({ page }) => {
  await page.goto('https://anupsahoo.github.io/progress-agent/customer-maint');
  await page.keyboard.press('Tab');
  await page.keyboard.type('1');
  await page.keyboard.press('Enter');
  await expect(page.getByLabel('Name')).not.toBeEmpty();
});
```
