# MAN-003: Two clerks edit the same customer at once

| Field | Value |
|---|---|
| Requirement | R5 |
| Priority | P2 |
| Technique | Exploratory |
| Suites | uat |
| Status | Approved |

## Preconditions
The customer maintenance screen is reachable at https://anupsahoo.github.io/progress-agent/customer-maint.

## Steps
1. Clerk A opens customer 3
2. Clerk B opens customer 3
3. Clerk A saves a change
4. Clerk B saves a different change

## Expected result
Clerk B is told the record changed and is asked to reload. Nobody's change is silently lost.
