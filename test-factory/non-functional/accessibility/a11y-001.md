# A11Y-001: Every customer field has a visible label

| Field | Value |
|---|---|
| Requirement | R3 |
| Priority | P1 |
| WCAG criterion | WCAG 1.3.1 Info and Relationships |
| Suites | regression |
| Status | Automated |

## Preconditions
The customer maintenance screen is reachable at https://anupsahoo.github.io/progress-agent/customer-maint.

## Steps
1. Look up customer 1
2. Check each of the six fields with a screen reader

## Expected result
Each field announces its label.

## Automated check
```ts
test('fields are labelled', async ({ page }) => {
  await page.goto('https://anupsahoo.github.io/progress-agent/customer-maint');
  for (const name of ['Name', 'Address', 'City', 'State', 'Postal code', 'Phone'])
    await expect(page.getByLabel(name)).toBeVisible();
});
```
