# VIS-001: Desktop, customer record loaded

| Field | Value |
|---|---|
| Requirement | R3 |
| Priority | P1 |
| Viewport / state | Desktop 1440, loaded record |
| Suites | regression |
| Status | Automated |

## Preconditions
The customer maintenance screen is reachable at https://anupsahoo.github.io/progress-agent/customer-maint.

## Steps
1. Open at 1440 px
2. Look up customer 1

## Expected result
Matches the approved baseline within 1% of pixels.

## Automated check
```ts
test('desktop loaded', async ({ page }) => {
  await page.setViewportSize({ width: 1440, height: 900 });
  await page.goto('https://anupsahoo.github.io/progress-agent/customer-maint');
  await page.getByLabel('Customer number').fill('1');
  await page.keyboard.press('Enter');
  await expect(page).toHaveScreenshot('desktop-loaded.png', { maxDiffPixelRatio: 0.01 });
});
```
