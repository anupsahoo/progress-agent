# VIS-002: Mobile, not-found error state

| Field | Value |
|---|---|
| Requirement | R2 |
| Priority | P2 |
| Viewport / state | Mobile 390, error state |
| Suites | regression |
| Status | Automated |

## Preconditions
The customer maintenance screen is reachable at https://anupsahoo.github.io/progress-agent/customer-maint.

## Steps
1. Open at 390 px
2. Look up 999999

## Expected result
Error banner matches the baseline.

## Automated check
```ts
test('mobile error', async ({ page }) => {
  await page.setViewportSize({ width: 390, height: 844 });
  await page.goto('https://anupsahoo.github.io/progress-agent/customer-maint');
  await page.getByLabel('Customer number').fill('999999');
  await page.keyboard.press('Enter');
  await expect(page).toHaveScreenshot('mobile-error.png');
});
```
